My Project Portfolio 

## Description

A simple and interactive portfolio application built with React and Tailwind CSS. This application allows users to view existing projects, add new projects, and search through projects by title.

## Features

Project Display: View a collection of existing projects.
Add Projects: Add new projects by entering a title and description.
Search Projects: Search and filter projects by title.
Dynamic Updates: Newly added projects appear immediately without refreshing the page.
Responsive Design: Layout adapts to different screen sizes using Tailwind CSS.
Reusable Components: Built using React components and props for better code organization.
